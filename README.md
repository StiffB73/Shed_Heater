This is a basic program that I got Grok to create to control a chinese diesel heater in my shed Using a Pi Zero running Rpitx and a $2 Temp/ Humidity sensor. 
I plan to try and learn exactly how the code works and modify/ streamline the project as time goes on. Hopefully using my own brain instead of Grok. 
It was more of an experiment more than anything to see what the AI could do for me and whether it even in fact worked, which so far it does seem to.
